## Abstract
Low frequency impedance or admittance experiments with reversible redox couples in well-supported quiescent electrolyte are normally analyzed using a semi-infinite Warburg element, a linearized model with one experimental fitting parameter. Because the reduced and oxidized species of a couple have distinct diffusivities, but linearized Warburg theory has a single fitting parameter, it is impossible to uniquely determine the individual diffusivities from a spectrum; information is lost by linearization. We present weakly nonlinear theory and experiments that extend traditional Warburg admittance analysis to include stationary and causal higher harmonic currents generated by single-sine potential modulations (5 – 20 $mV_{RMS}$) at a Pt electrode in well-supported ferri-/ferro-cyanide electrolyte. Our data processing enables direct analysis of raw harmonic data from a commercial instrument by aligning measurements with theory. The theory is formulated to show the role of electrochemical inversion symmetry in the resulting harmonic spectrum, where even-numbered harmonics are nullified in the high symmetry situation of equal species diffusivities. Analysis of first and second harmonic Warburg admittance show how the theory fails as $\frac{∆E*F}{RT}$ exceeds unity. First and second harmonic currents are measurable for ∆E ≥ 5 $mV_{RMS}$ and show optimal balance between the applicability of weakly-nonlinear theory and experimental signal quality near ∆E ≈ 10 $mV_{RMS}$. Using both the first and second harmonic experimental signals, theory has two distinct fitting parameters enabling unique determination of the individual ferricyanide and ferrocyanide diffusivities. In short, analyzing the first and second harmonics generated simultaneously with moderate amplitude modulations eliminates any information lost through linear Warburg analysis of first harmonic alone.

* Python (3.11.14)
* SciPy (1.16.3)
* NumPy (2.4.0)

* `conda env create -f environment.yml`
* `conda activate FerriFerroExp`

## Folders
* `Raw Data - FeCN platinum 8`: contains the raw .DTA file outputs from a Gamry Interface 1010E potentiostat for RMS potential modulations of 1 mV, 5 mV, 10 mV, 20 mV, 50 mV, and 100 mV. Files ending in 1 are associated with the Run (or replicate) 1 and those ending in 2 are Run 2.
* `jupyter`:
  * `Figures`: contains the jupyter notebooks used to generate the Figures in the paper and supplementary materials, along with their .pdf images.
  * `Processed Data`: contains the jupyter notebook `preprocessing_data.ipynb` used to preprocess the raw data from the `Raw Data - FeCN platinum 8` folder into the file `preprocessed_data_final.csv`, according to the methods described in the paper. This .csv file was used to create all the resulting Figures.
  * `Theory Derivations`: contains the jupyter notebook `Tutorial_Supplementary_SympyHarmonicExpansions.ipynb` used to mathematically derive the ordered-models for the first and second harmonic current and admittances.
